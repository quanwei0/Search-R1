# Search-R1 Development Setup Guide

## Step 1: Install Retriever Environment

Run commands step by step in `retriever_setup.sh`:
```bash
bash retriever_setup.sh
```

## Step 2: Install SearchR1 Environment  

Run commands step by step in `searchr1_setup.sh`:
```bash
bash searchr1_setup.sh
```

## Step 3: Download Dataset

Download the required dataset:
```bash
bash download_data.sh
```

## Step 4: Run Training Script

Execute the PPO training script:
```bash
bash New_train_ppo_7b_gae_turn_level_IS_total_epoch_4_Minibatch256_seed1_nq.sh
```
